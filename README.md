# Новый тур

Виртуальный тур на основе [Pannellum](https://pannellum.org/).

## Структура
- `index.html` — главная страница тура
- `panoramas/` — папка с панорамными изображениями

## GitHub Pages
Чтобы опубликовать сайт:
1. Перейдите в Settings → Pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root)
4. Save

Сайт будет доступен по адресу: https://berengow.github.io/novyy-tur/

**Важно:** Загрузите два файла панорам в папку `panoramas/` (из прикрепленного архива), так как автоматическая загрузка бинарных файлов через API ограничена.
